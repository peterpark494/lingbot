# 50 项任务比赛记录

以下来自 2026-10-21 参赛资料。原图存于 [media/report](../media/report/)，逐任务数据转录至 [tasks.csv](../results/tasks.csv)。

| 项目 | 参赛记录 |
| --- | --- |
| 数据 | 官方 Clean50，50 项 × 50 条示范，共 2,500 条 |
| 训练资源 | 8 × 80 GB，每卡 batch 32，梯度累积 1，总 batch 256 |
| 第一阶段 | 基础图像增强、均匀任务采样、低运动窗口降权，20k 更新，基准 LR 1e-4 |
| 续训阶段 | 保留前段策略，增加图像增强，基准 LR 2e-5，记录配置为续训 10k、每 1k 保存 |
| 选用模型 | 20k + 2k，未开启状态扰动 |
| 数值精度 | FP32 权重、混合精度训练，FP32 评测 |
| 动作 chunk | 50 |
| 速度 | 续训末段 100 步平均 5.62 秒/步，中位数 5.60 秒/步 |
| 数据加载 | 每卡 16 workers，共 128，申请 CPU 32 核 |

低运动窗口降权减少近静止动作窗口的采样权重。资料未给出可核实的具体窗口判定代码和完整配置，因此这里只记录策略，不给出声称等价的实现。

## Random / unseen 历史对照

| 配方 | 更新数 | 成功率 |
| --- | --- | ---: |
| 原始基线（50×100） | 20k | 31.40% |
| 增广，chunk 50 | 20k | 39.3% |
| 增广，chunk 25 | 20k | 39.3% |
| 增广 | 30k | 38.2% |
| 均匀采样续训 | 20k + 3k / 6k / 10k | 42.9% / 43.1% / 42.6% |
| 状态扰动 | 20k + 3k / 6k / 10k | 41.8% / 43.9% / 42.7% |
| 低运动降权 | 15k / 20k / 25k | 37.2% / 42.8% / 37.2% |
| 丰富增广 | 20k + 2k / 5k | 48.1% / 46.3% |

其余 14 组为 50×20 筛选评测。48.1% 对应筛选规模，48.28% 对应 5,000 回合最终口径。早期对照的样本量、推理后端或训练配置有变化，差值不能归因于单一策略，也不能相加。
